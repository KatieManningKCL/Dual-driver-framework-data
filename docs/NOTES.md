# Notes

This repository packages the survey analysis files for the dual-driver NbS paper.

- `code/NbS_TUSSIE.R` is the main R workflow.
- `data/` contains the Qualtrics exports needed to rerun the script.
- `outputs/` contains selected tables and figures.
- Large TIFF/AI figure masters are not included.

See `docs/DATA_DICTIONARY.md` for Qualtrics item IDs.
